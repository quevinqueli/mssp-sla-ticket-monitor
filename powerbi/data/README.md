# Star-schema CSVs

Generated by `python3 scripts/export_powerbi_star.py` from `data/synthetic_tickets.csv` at `data/DEMO_AS_OF.txt`. Do not hand-edit KPI flags.

Boolean-like flags are **0/1 whole numbers** so DAX `= 1` is stable (Power Query True/False would break those measures).

| File | Grain |
| --- | --- |
| `fact_ticket.csv` | CSV row |
| `fact_finding.csv` | Phase A evidence row |
| `dim_client.csv` | Client id from the CSV (not enriched) |
| `dim_priority.csv` | P1–P4 + UNKNOWN |
| `dim_status.csv` | Normalized status |
| `dim_attention_reason.csv` | Primary reason keys |
| `dim_snapshot.csv` | Frozen as-of + synthetic disclaimer |
| `expected_measures.json` | Unfiltered KPI values for tests |

ISO timestamps use `+00:00`. Treat them as UTC in Desktop.
